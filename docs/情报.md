## 3. 鉴权形态

| 头 | 值 | 是否可变 |
|---|---|---|
| `app-id` | 小程序 AppID | 固定 |
| `user-id` | **openId**（微信用户标识，`o_` 开头 28 字符） | 身份凭据 |
| `version` | `V3.8.0-20250613` / `V3.7.7-20240717` | 两套并存 |
| `qr-code` / `scene-code` / `page-path` | 扫码上下文 | 辅助 |

**无签名、无时间戳、无 nonce、无 cookie**。openId 由 `/front/user/getOpenId?code=` 用
`wx.login` 的 code 换取，之后每次请求以 `user-id` 明文回传。

## 5. 风控特征

- 未观察到签名、加密参数、设备指纹校验（`X-Sign`/`EDK` 类均无）。
- 唯一频控信号：`addOrder` 返回空 orderId 时客户端提示「操作太频繁啦，请3秒后再试」。
- 服务端对空参数返回 500 + `rid`，可用于区分「参数缺失」与「业务拒绝」。

## 6. 边界

- 设备物理副作用只有「开柜」一处；本工程不做跨设备遍历。
- openId 属个人身份标识，仅存密钥库。
