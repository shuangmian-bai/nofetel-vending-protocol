# 配置与凭据

本文件说明：哪些配置放哪里、openId 怎么配、换设备要改什么。

## 一、配置文件

| 文件 | 是否入库 | 内容 |
|---|---|---|
| `config/.env.example` | 是 | 全部配置项的模板与说明，值留空 |
| `config/.env` | **否**（`.gitignore` 已排除） | 你自己填写的实际值 |

首次使用：

```bash
cp config/.env.example config/.env
chmod 600 config/.env          # 见第四节的安全提示
${EDITOR:-vi} config/.env
```

## 二、配置优先级

统一为：**命令行参数 > 环境变量 > `config/.env`**

以设备 ID 为例，三种写法都行：

```bash
.venv/bin/python main.py --dev-id <DEVICE_ID> info          # 1. 命令行
NOFETEL_DEVID=<DEVICE_ID> .venv/bin/python main.py info     # 2. 环境变量
.venv/bin/python main.py info                               # 3. 用 config/.env
```

临时换设备用前两种，不必改文件；日常用第三种。

## 三、配置项一览

| 配置项 | 必填 | 说明 |
|---|---|---|
| `NOFETEL_DEVID` | 是 | 设备主键。设备二维码标签印字，或二维码 URL 的 `?devid=` 值 |
| `NOFETEL_OPENID` | 是 | 微信用户在该小程序的 openId，服务端以 `user-id` 头识别身份 |
| `NOFETEL_APP_ID` | 否 | 请求头 `app-id`，默认已给 |
| `NOFETEL_CLIENT_VERSION` | 否 | 请求头 `version`，默认已给 |
| `NOFETEL_BASE_URL` | 否 | 后端地址，默认已给 |
| `NOFETEL_MAX_ORDER_AMOUNT` | 否 | 单笔金额上限（元），默认 50 |
| `NOFETEL_PAY_POLL_INTERVAL` / `NOFETEL_PAY_POLL_MAX` | 否 | 支付轮询间隔与次数，默认 1.5 秒 / 100 次 |
| `NOFETEL_BLE_SERVICE` / `_NOTIFY` / `_WRITE` | 否 | BLE 特征 UUID，N 系列默认已给 |

**不写入任何地方**的东西：`sessionKey`、`payCode`。前者只存在于客户端，后者由服务端
在支付成功后随 `/front/smallWxpay/getPayStatus` 下发，程序在内存中使用后即丢弃。

## 四、openId 的安全提示

openId 等同于你在该小程序的账号身份：服务端不做二次校验，谁拿到它就能以你的身份下单。

因此：

1. **确认 `.env` 的权限真的生效**：

   ```bash
   chmod 600 config/.env && stat -c %a config/.env    # Linux 期望 600
   ```

2. **如果权限不生效**（NTFS/exFAT 等无 POSIX 权限位的磁盘，`chmod` 后仍是 777），
   文件对该机所有用户可读，此时**不要把 openId 写进 `.env`**，改用环境变量：

   ```bash
   read -rs NOFETEL_OPENID && export NOFETEL_OPENID
   .venv/bin/python main.py info
   ```

3. **不要把 `config/.env` 提交或分享出去**。`.gitignore` 已包含它；
   若你手动 `git add -f` 或复制到别处，等于公开自己的身份。

程序同时支持两种来源，`.env` 里留空时会自动回落到环境变量。

## 五、如何取得 openId

见 README 的「如何取得 openId」一节。要点：openId 来自微信登录流程，
需要在客户端侧获取；微信 `code` 一次性、约 5 分钟过期。

## 六、换设备时要改什么

只改 `NOFETEL_DEVID` 一项。机型差异（货道数、是否密码柜、能否联网）由程序在运行时
通过 `/front/dev/getModelConfig` 读取，不需要写在配置里。

例外：若新设备的 BLE 特征与其他机型不同（非 N 系列），需要相应调整
`NOFETEL_BLE_SERVICE` / `_NOTIFY` / `_WRITE`。

## 七、常见错误

| 终端提示 | 原因 | 处理 |
|---|---|---|
| `缺少设备主键 devId` | 三处都没配 | 填 `config/.env` 或设环境变量或加 `--dev-id` |
| `未配置 openId` | 同上，针对身份 | 填 `NOFETEL_OPENID` 或设环境变量 |
| `设备未入库:XXXX` | devId 写错，或该设备不在服务端 | 核对二维码上的印字 |
| `写操作需要身份` | 没有 openId 就想下单 | 配置身份后重试 |
| `金额 X 超过闸门 Y` | 合计超过 `NOFETEL_MAX_ORDER_AMOUNT` | 减少数量，或按需调整该项 |
