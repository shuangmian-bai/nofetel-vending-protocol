# 接口清单（Phase 1）

逐接口登记。所有条目实测日期：**2026-11-18**，实测方式：本项目 CLI 跑通 / curl 只读核实。

**通用约定**（全部接口适用）

- Base：`https://1.nofetel.com/VendingSystem`
- 方法：多数 GET（参数走 query），写操作 POST（JSON body 或 query）
- 头：`app-id` / `user-id`(openId) / `version` / `qr-code` / `scene-code` / `page-path`
- 响应：HTTP 恒 200；`{"success":bool,"message":str,"code":int,"result":any}`
- 业务成功判定：`code == 200`

---

## 1. `/front/dev/getModelConfig`

1. **接口信息**：GET，参数 `devId`，无版本号
2. **请求参数**：`devId`（必填，设备主键）
3. **加密方式**：无
4. **验证码**：无
5. **实现方案**：`pyapp/api/device.py::get_model_config`
6. **返回要点**：`name` `model` `baseModel` `cellNum` `connectBluetooth` `connectNetwork`
   `hasPwd` `reopen` `replenishType` `entrustedMode`
7. **用途**：判定是否走蓝牙开柜、是否有多个货道、是否密码机型

## 2. `/front/dev/info`

1. **方法**：GET，参数 `devId`
2. **返回要点**：`devId` `model` `hotelId` `roomCode` `status`(1 正常/0 离线/2 故障/5 禁用)
   `blueToothId` `softVersion` `standbyVoltage` `bind`
3. **实现**：`pyapp/api/device.py::get_device_info`
4. **注意**：`hotelName` 可能为空，酒店详情以 `/front/hotel/info` 为准

## 3. `/front/item/info`

1. **方法**：GET，参数 `devId`
2. **返回要点**：`itemInfo[]`，每项 `cellId` `itemId` `itemNo` `itemName` `itemPrice`
   `itemNum`（库存）`sellStatus` `itemPic` `specs`
3. **实现**：`pyapp/api/device.py::get_cell_items`
4. **下单所需字段**：`itemId` / `cellId` / `sellStatus` / `itemNo`

## 4. `/front/order/addOrder`（写）

1. **方法**：POST，JSON body
2. **请求结构**（客户端 `orderInfo`）：
   ```json
   {"devId":"<devId>","items":[{"itemId":"...","cellId":1,"sellStatus":..,"sellNum":1,"itemNo":"..."}]}
   ```
3. **返回**：`{"orderId": "..."}`；若被频控则 `orderId` 为空 → 客户端提示「操作太频繁啦，请3秒后再试」
4. **实现**：`pyapp/pay/order.py::create_order`
5. **门禁**：`confirm=True` + 金额 ≤ 闸门
6. **实测**：未执行真实下单（见 `docs/逆向计划.md` 剩余验证项）

## 5. `/front/smallWxpay/unifiedOrder`（写）

1. **方法**：POST，参数走 query：`orderId=<id>`
2. **返回**：`timeStamp` `nonceStr` `packageValue` `signType` `paySign`
3. **用途**：喂给 `wx.requestPayment`（JSAPI）。Linux 侧没有微信客户端，无法自行调起支付
4. **实现**：`pyapp/pay/order.py::unified_order`
5. **门禁**：`confirm=True`

## 6. `/front/smallWxpay/getPayStatus`

1. **方法**：GET，参数 `orderId` `isCharge` `isNeedPwd`
2. **返回**：`status`（**1 或 12 = 已支付**）、`payCode`（开柜十六进制指令）、`pwd`（密码机型）
3. **客户端轮询**：间隔 1500ms，最多 100 次（`pages/index/index.js::getPayStatus`）
4. **实现**：`pyapp/pay/order.py::get_pay_status` / `wait_for_payment`
5. **特殊值**：`5001` = 购物车购买时蓝牙断开
6. **这是全链路唯一的开柜指令来源**

## 7. `/front/user/getOpenId`

1. **方法**：GET，参数 `code`（`wx.login` 一次性 code）
2. **返回**：`openId` `sessionKey` `hasPhone`
3. **实测**：code 为空返回 `500 missing code, rid: ...`
4. **本工程替代方案**：不从设备侧换 code，而是从运行中的小程序进程内存取 openId 存入密钥库
   （root 设备，进程 `com.tencent.mm:appbrand0`）。**已实测可直接用于 `user-id` 头**

## 8. `/front/wxPayInfo/info`

1. **方法**：GET，参数 `devId`
2. **返回要点**：`payWay`（0=小程序内支付，1=邮寄支付）、`appid`、`showCustomer`、`checkTime`
3. **用途**：判定支付通道，决定是否走 `unifiedOrder`
4. **实测**：本设备 `payWay=0`

## 9. `/front/user/getUserInfo`

1. **方法**：GET，参数 `devId`
2. **返回**：用户档案（`openId` `nickName` `partner` `phone` …）
3. **用途**：验证 openId 有效性（只读探针）

## 10. `/front/hotel/info`

1. **方法**：GET，参数 `hotelId`
2. **实测**：本设备 hotelId 查询返回「设备未绑定」占位对象 —— 推断该接口按 hotelId 查的是另一套
   酒店档案表，设备侧信息以 `/front/dev/info` 为准

## 附：蓝牙开柜帧（非 HTTP）

|---|---|---|
| 服务/写入特征 | `0000AE01-0000-1000-8000-00805F9B34FB` | `pages/index/index.js` |

| 开柜帧 | **服务端下发的 `payCode`**，本地不生成 | `getPayStatus` |
