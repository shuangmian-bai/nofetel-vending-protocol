## 明确不做

| 项 | 原因 |
|---|---|
| 逆向固件里的 payCode 校验算法 | 需要固件镜像与设备拆解，超出协议还原范围 |
| 跨设备遍历 / 批量下单 | 项目定位与 `CLAUDE.md` 边界禁止 |
| 绕过支付直接开柜 | 无技术路径（payCode 由服务端签发）；也不属于本项目目的 |
| 自动完成微信支付 | JSAPI 需要微信客户端环境；不做伪造支付 |
